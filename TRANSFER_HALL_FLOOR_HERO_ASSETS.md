# Transfer Hall Floor Hero Assets

These four files are floor hero setpieces, not generic repeatable floor tiles.

Each asset is exactly 128 x 128 px and is authored as a 2 x 2 grid of 64 x 64 tiles. Cell order is NW, NE, SW, SE.

Files:
- transfer-hall-floor-hero-calm-base.png
- transfer-hall-floor-hero-service-slot.png
- transfer-hall-floor-hero-machinery-recess.png
- transfer-hall-floor-hero-core-socket.png

Keep each four-tile composition together in map authoring. Do not scatter its quadrants as generic floor variants. These assets do not replace the normal repeatable base floor. Validate the complete 2 x 2 composition at gameplay scale before live placement.
