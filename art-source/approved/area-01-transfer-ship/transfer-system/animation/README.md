# Transfer System — Animation Sources

Store future animation-authoring source files and exports that combine or animate members of the Transfer System family.

Examples may include layered editor projects, rig/turnaround inputs, motion-source exports or animation-specific high-resolution composites.

Animation work must continue to reference the immutable approved originals in `../source/` and approved FX originals in `../fx/`; it must not overwrite them.
