# Numberdroid Art Source Archive

Status: **historical source material; not current production authority**

This directory preserves superseded art-authoring sources that still have learning/reference value but are no longer consumed by the current runtime or production recipes.

Rules:

- current/reproducible production source belongs in `art-source/recipes/`;
- archived sources must not be treated as current geometry/material authority;
- keep archive entries only when they carry useful evidence not already adequately represented by current recipes/documentation;
- transport/intermediate artifacts with no continuing reference value may be deleted because Git history already preserves them.

Current archive:

- `controlled-art-pass-wall-blueprint/` — original Transfer Hall wall SVG/raster guide used to establish the M2 deterministic-geometry art-pass workflow; superseded by recipe-local TS-01 wall geometry and the live-accepted M4 compositor.
