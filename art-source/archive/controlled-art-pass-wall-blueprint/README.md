# Historical Transfer Hall Controlled-Art-Pass Wall Blueprint

Status: **ARCHIVED / SUPERSEDED**

These two files were the original deterministic Transfer Hall wall guide used during the M2 Controlled Art Pass experiments:

- `transfer-hall-wall-blueprint.svg` — original compact wall geometry proof;
- `transfer-hall-wall-blueprint-4x.png` — derived large raster guide used for inspection/edit experiments.

They are preserved because they document the experiment that established deterministic geometry + generative material as a useful separation of responsibility.

They are **not** current TS-01 wall production sources. Current Walls are live-accepted M4 assets governed by:

- `art-source/recipes/transfer-hall/walls/`
- `docs/art/transfer-hall/TRANSFER_HALL_WALL_KIT.md`
- `scripts/render-transfer-hall-walls.mjs`

Do not copy these archived files back into a production recipe unless a deliberate historical reproduction is required.
