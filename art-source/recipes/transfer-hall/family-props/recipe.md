# Asset Recipe — TS-01 Family Props

Status: `PLANNED` — complete per micro-set/prop before generation.

## Visual purpose

Family props communicate human/personal traces inside a highly ordered machine society. They should feel warm, slightly irregular and meaningful without becoming rustic or visually noisy.

Candidate set from the approved direction:

- family table / waiting module;
- cups or mismatched drinking containers;
- bag / fabric item;
- plant(s);
- child drawing / keepsake / personal display item.

## Binding constraints

- strict orthographic top-down environment perspective;
- isolated transparent objects; no baked floor or wall;
- each object/set has a deliberate runtime footprint and separate collision where needed;
- contact shadow only in a small local envelope;
- warm/personal accents are local, not global grading;
- no filler clutter.

## To author before generation

For each prop or deliberate micro-set:

- exact `geometry.svg` / footprint guide;
- runtime cell footprint and extraction plan;
- material reference (fabric/ceramic/plastic/plant etc. as appropriate);
- dedicated material-edit prompt;
- transparency/contact-shadow envelope;
- gameplay-scale and map-context QA.

Do not reuse the current placeholder prop atlas as authoritative source geometry.
