# TS-01 Transfer Apparatus — M1 Source Prompt v1

Status: **FIRST SOURCE PASS — one generation, then stop for source QA**

Create one isolated production-source image of the Numberdroid TS-01 Transfer Apparatus / Core Cradle.

## Camera / projection

- orthographic near-top-down game asset, no perspective convergence;
- near-nadir view consistent with Numberdroid ND Shallow Top-Down, approximately 8–10° away from perfect vertical;
- top surfaces dominate; side faces are only narrow depth cues;
- square source composition intended to downscale into a 3×3 tile runtime envelope;
- transparent background; no room, floor, wall, text, labels or framing board.

## Object concept

A beautiful civilian transfer machine for a future society where a person's persistent technical CORE can be moved between robot bodies.

The machine must visually express the Numberdroid CORE / SLOT grammar:

- a clearly readable precious warm amber CORE at the center;
- an elegant open SLOT / cradle structure around it, using paired brackets, precise docking recesses and alignment geometry;
- the form should read as a transfer/docking apparatus, not a chair, altar, weapon, engine, reactor or medical horror device;
- optimistic, maintained, precise and empowering;
- deliberately attractive enough that a child would want to use it;
- visually important environmental hero object, but still believable civilian machinery.

## Physical mass / silhouette

- compact central physical machine body; do not fill the complete square canvas with solid machinery;
- centered object with generous transparent margin;
- central physical mass should read roughly as 55–65% of the final 3×3 runtime envelope;
- use an open, readable silhouette with negative space between bracket elements;
- outer visual language may imply alignment / SLOT structure, but do not create huge raised arms that would require a full 3×3 gameplay collider;
- no baked floor plate or giant base rectangle.

## Materials

- primary: warm off-white / ceramic-grey precision shell;
- secondary: graphite / dark mineral mechanical recesses;
- accents: restrained system mint/teal only for small normal-status indicators;
- focal emissive: warm amber/gold CORE, clearly stronger than the teal accents;
- premium clean industrial design, soft rounded masses plus precise inset technical frames;
- subtle material richness and believable manufactured joints, not noisy greebles.

## Lighting / shadow ownership

- local self-emission on the CORE is allowed;
- no broad cast glow onto a floor/background;
- no baked scene lighting;
- no large cast shadow; grounding shadow will be authored as a separate FloorFX asset;
- transparent pixels outside the object.

## Avoid

- dark military sci-fi;
- villain-black machinery;
- hazard stripes;
- excessive cyan neon;
- hexagon wallpaper;
- random vents/pipes/greebles;
- visible text or symbols requiring reading;
- frontal screens;
- side-view furniture perspective;
- biological/organic horror;
- giant reactor turbine;
- throne/altar imagery;
- humanoid robot body in the asset;
- floor or environment background.

## Source QA target

At a future 192×192 runtime size, the object should still read immediately as:

**warm central CORE + precise open SLOT / transfer cradle**.
