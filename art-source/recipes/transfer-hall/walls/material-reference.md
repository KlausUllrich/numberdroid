# TS-01 Walls — Material Reference

## Primary approved material source

Use the accepted Gold-Slice graphite wall material already preserved in the repository:

```text
art-source/runtime/transfer-hall-architecture-16px.b64.00
art-source/runtime/transfer-hall-architecture-16px.b64.01
```

`npm run materialize-art` reconstructs the current runtime wall atlas from controlled sources/post-processing. The source is useful for graphite/metal character, edge treatment and restrained wear. It is **not** authoritative geometry.

## V3 refinement target

Live comparison against the approved Transfer Hall reference shows that the current material should become visually quieter:

- thicker architectural mass;
- more homogeneous dark graphite body;
- broader calm value fields;
- fewer bright metallic edge highlights;
- fewer small panel/vent-like accents;
- less repeated local contrast;
- no cyan/teal decoration on ordinary structural seams;
- enough subtle edge/contact shading to separate wall from floor without turning the wall into a focal prop.

The wall should frame the room and recede behind PICO, doors, props and the Transfer apparatus.
