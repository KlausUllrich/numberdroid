# Game Design Source of Truth

The detailed current design is documented in `../CODEX_HANDOFF.md`.

This file intentionally does not duplicate the complete rules. Its purpose is to establish the hierarchy of authority:

1. Explicit user decisions documented in `CODEX_HANDOFF.md` and `DECISIONS.md`.
2. Current clean implementation in `src/`.
3. Frozen v7 standalone prototype as behavioral/visual reference.

If implementation and the confirmed decisions conflict, the confirmed decision wins.

If the v7 prototype contains placeholder content that was never approved (for example placeholder KRONOS abilities), do not promote it into a production rule merely because it appears visually in the prototype.
