# M4 Demos

Demos are minimal reproducible method proofs, not production assets.

The first wall demo should progress in this order:

1. `H_TOP` single tile;
2. `H_TOP × 3` continuous run;
3. one corner with two neighbors;
4. one T-junction with divider;
5. full semantic wall kit.

Each demo should preserve:

- input geometry/mask;
- input material;
- render settings;
- output PNG;
- assembly preview;
- measured QA values where applicable.

A demo may use simplified material. Its purpose is to prove the compositor mechanic before committing the method to production art.
